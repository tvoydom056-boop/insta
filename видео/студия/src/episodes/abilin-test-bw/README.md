# Абилин: тест картинки

Только тест первых 15,87 с (476 кадров), до конца слова «кондиционера».
1080×1920, 30 fps, семь сцен, SVG на бумаге в стиле существующего `piter-bw`.
Полный ролик не собран: по `ЗАДАЧА-ДЛЯ-CODEX.md` сначала нужно одобрение теста.

звук на 15,867 с: конец последнего слова округлён вверх плюс два кадра.
В тесте нет белого ухода: последний рисунок остаётся до конца.

## Повторный рендер

Из `видео/студия`:

```powershell
npm run typecheck
npx remotion render src/index.ts AbilinTestBwBoard out/abilin-test/b --sequence --image-format=png --concurrency=2
npx remotion render src/index.ts AbilinTestBw out/abilin-test/abilin-test.mp4 --concurrency=2
```

Артефакты в `out/abilin-test` (папка исключена из Git):

- `abilin-test.mp4`: тест для просмотра;
- `board.png`: семь планов на одном листе;
- `b/element-0.png` … `b/element-6.png`: исходные кадры раскадровки;
- `sync.png`: пары кадров до и после ключевых появлений из готового MP4.

Копии MP4, раскадровки и листа проверки для просмотра из GitHub сохранены
в `инста/выдача/абилин-тест/` от корня репозитория.

## Проверка

- Заголовки на 2–6 слов, монохромные чернила и белый фон, толпа, шутка с расхождением мыслей и ответа.
- Просмотрены все планы раскадровки. После просмотра тесть в сцене жары заменён кактусом; раскадровка пересобрана.
- Готовый MP4 проверен через ffprobe: H.264, 1080×1920, 30 fps, 476 кадров; AAC 48 кГц. Длительность видеопотока 15,867 с, контейнера 15,915 с из-за дополнения AAC; оба заканчиваются до следующей фразы.
- Из готового MP4 извлечены и просмотрены 14 кадров до/после семи ключевых событий (`sync.png`). Появления на месте, пересечений надписей с героями не найдено.
- Важные элементы выше нижних 350 px. Внизу только бумага, штриховка и дорога.
- В каждом плане есть движение: живые контуры, приближение камеры, жесты, стрелки, жара или колёса.
- `npm run typecheck` проходит. Исправлена существующая ошибка типа аргумента `size` в `Root.tsx`: добавлено общее поле `id`; поведение не менялось.
- Совпадение исходной и скопированной озвучки проверено по SHA-256. Текст, исходная разметка и WAV не менялись; новый голос, музыка и эффекты не создавались.
- Произношение и субъективная синхронность на слух не проверялись. Границы слов взяты из готовой приблизительной ASR-разметки.
- Уникальный фирменный признак не выбирался: использован заданный стиль проекта. Дальнейшие сцены требуют одобрения этого теста.
