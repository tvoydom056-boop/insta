# codex-тест: ЧБ-ролики, тестовая задача
**Сначала открой `ЗАДАЧА-ДЛЯ-CODEX.md`.**

Чистая выжимка проекта. Всё, что нужно, чтобы понять и повторить удачный ролик (80–100 с, 1080×1920, ЧБ-человечки, клон голоса), без черновиков и тестов.

## Как работать Codex

Работай экономно: минимум необходимого контекста и вывода инструментов, с сохранением обязательных проверок и полного выполнения порученной задачи.

- Используй уже полученный контекст. Через `rg` находи нужные разделы и реализации; читай только относящиеся к задаче фрагменты. Не перечитывай неизменившиеся файлы.
- Длинные логи и большие результаты сохраняй в файл; в контекст выводи ошибки, нужные поля и итог. Не опрашивай долгий рендер каждые несколько секунд.
- Соблюдай объём задания. Дополнительные исследования, варианты, тесты и артефакты делай, только если они нужны для результата или проверки существенного риска.
- Проверяй соразмерно изменению: текст — вычиткой, код — подходящей проверкой, рисунок — просмотром раскадровки. Выполняй проверки из задания; расширяй или повторяй их при новых изменениях, ошибках или нерешённых сомнениях.
- При сбое выясни причину и исправь команду; не повторяй неизменившуюся неудачную попытку. Учитывай Windows и PowerShell.
- При обычной неоднозначности выбирай разумное обратимое решение и продолжай. Уточняй только то, что существенно меняет результат или необходимо для действия.
- Отвечай по-русски, кратко: результат, чем проверен, существенные ограничения. Отделяй проведённую проверку от непроведённой.

**Порядок чтения для ИИ-агента (Codex, Claude):**

1. `ЗАДАЧА-ДЛЯ-CODEX.md`: текущая тестовая задача, читать первой.
2. `видео/README.md`: главный рецепт; прочитай разделы, указанные в задании, остальные — по необходимости. В разделе 1 таблица соответствия старых путей новым.
3. `видео/эталон-30с/ИНСТРУКЦИЯ.md`: при работе над рисунком — раздел про сцены. Озвучка там устарела; актуальный процесс в `видео/README.md`, раздел 5.
4. `инста/README.md`: при поиске идей и проверке спроса.

## Быстрый старт

```
cd видео\студия
npm install
npx remotion studio src/index.ts --port 3430
```

Озвучка требует модель F5-TTS и окружения Python (в копию не входят, см. `видео/README.md`, раздел 1). Правило проекта: сначала тест на ~15 секунд, полный рендер только после одобрения.
