# codex-тест: ЧБ-ролики, тестовая задача
**Сначала открой `ЗАДАЧА-ДЛЯ-CODEX.md`.**

Чистая выжимка проекта. Всё, что нужно, чтобы понять и повторить удачный ролик (80–100 с, 1080×1920, ЧБ-человечки, клон голоса), без черновиков и тестов.

**Если ты ИИ-агент (Codex, Claude), которому дали эту папку: читай в таком порядке.**

1. `видео/README.md`: главный документ, весь рецепт от идеи до рендера (разделы 0–9). В разделе 1 таблица соответствия старых путей новым.
2. `ЗАДАЧА-ДЛЯ-CODEX.md`: тестовая задача (читай первой).
3. `видео/эталон-30с/ИНСТРУКЦИЯ.md`: эталонный ролик «Принцип Питера» на 30 с, как рисуются сцены (озвучка там устарела, актуально из `видео/README.md`, раздел 5).
4. `инста/README.md`: откуда берутся идеи и как проверять спрос.

│   ├── README.md          рецепт (главный)

## Быстрый старт

```
cd видео\студия
npm install
npx remotion studio src/index.ts --port 3430
```

Озвучка требует модель F5-TTS и окружения Python (в копию не входят, см. `видео/README.md`, раздел 1). Правило проекта: сначала тест на ~15 секунд, полный рендер только после одобрения.
